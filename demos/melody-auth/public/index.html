Admin Upstream
You can run your own standards-compliant sign-in server on Workers + D1 + KV. What you could build: SSO for your own apps, auth without a SaaS IdP, or a login box at the edge.

Sample app

Sign in with PKCE. Read the tokens.

What this shows The sample app starts an authorization-code flow with PKCE S256. The hosted page signs you up or in. This page then shows the ID token claims and /userinfo.

Try it: create an account, come back through sign-in, refresh the access token, then sign out. Demo users expire after 24 hours. No email is sent.
