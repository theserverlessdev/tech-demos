Authorization code + PKCE (the Google web/native flow), client credentials (machine-to-machine), device code (TV/CLI), then introspect, refresh, and revoke. Implicit and password grants are rejected on purpose — OAuth 2.1 removed them.

Sign in, then exchange the code

  1. Register a public client via DCR (Turnstile) or use melody-sample.
  2. Redirect to /authorize with S256.
  3. Consent, then POST /token.

client_credentials

Machine-to-machine

DCR a confidential client, then POST grant_type=client_credentials with client_secret_post. The access token is at+jwt (RFC 9068).

RFC 8628

Device authorization

Start a device grant, open /device, type the user code, approve, then poll. Polling too fast returns slow_down.
