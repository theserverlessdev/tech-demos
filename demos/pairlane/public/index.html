Workers + Durable Objects

Send a file to the other browser

The Durable Object only introduces the two browsers. The file moves on a WebRTC data channel and never touches this server.

  • Proves Signalling-only rooms. Offers, answers, and ICE pass through the object. File bytes stay on the data channel.
  • Try Create a room, scan the QR code, and send a file. The side panel lists what the object sees, with live progress and speed.
  • Build A handoff for a screenshot, a scan, or homework that never lands in an upload bucket.

Rooms last 10 minutes and hold two peers. Misuse can be reported.
