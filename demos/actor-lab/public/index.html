    What the race is showing

    Input gate

    This actor is one JavaScript thread. While it waits on SQLite, Cloudflare does not start the next request. When it waits on Workers AI, that hold lifts, and another update can read the same counter before this one writes.

    Output gate

    The response stays here until the SQLite write is confirmed. If the actor is evicted first, the write rolls back and the caller gets an error instead of a success that never landed.

    Mailbox and blockConcurrencyWhile

    Serialized mode is the durable-actors default: handlers take a number and run one at a time, even during the model wait. Interleaved mode is their @Interleave opt-out. blockConcurrencyWhile keeps the input gate shut for a whole wait. This actor uses it only while loading SQLite. Holding it across Workers AI would stall every other event for as long as the model takes, so the mailbox does that job instead.
